One star. Monday cancelled my 9 a.m. planning meeting at 8:59 and replaced it with a meeting to discuss the cancellation. That is the whole review: a real Monday, a concrete time and meeting, and the joke landing in the last six words. The program writes exactly that one line, 121 characters, to `entry.txt` — nothing else, no title, no explanation.

## Run it

```sh
python3 main.py
```
